# CPLfold energy parameter subset

These are the eight data tables consumed by `Utils/hotknots_energy.py` for the
FM363, DP03/DP09, CC06/CC09, and RE energy models. They are copied from the
HotKnots 2.0 parameter distribution so CPLfold's runtime does not depend on the
HotKnots source tree, wrapper, shared libraries, or executable.

The model provenance and parameter layout are documented in
[`docs/hotknots_energy_analysis.md`](../../docs/hotknots_energy_analysis.md).
